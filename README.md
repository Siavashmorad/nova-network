# NOVA Network

NOVA is an independent Layer-1 blockchain project focused on deterministic finality, predictable fees, parallel execution, and mobile-first infrastructure.

## Milestone 1.1

This initial workspace establishes the Rust foundation for:

- core protocol types
- Blake3 hashing
- deterministic account state transitions
- durable file storage primitives
- a minimal node core
- GitHub Actions CI

This is a development foundation, not a mainnet implementation. Consensus, canonical protocol encoding, Merkleized state, networking, RPC, validators, and production cryptography are implemented in later milestones.
